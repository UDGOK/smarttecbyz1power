# Embroidery source artwork — digitizing required

These EPS and SVG files are artwork for an embroidery shop. **They are not stitch programs. No DST, PES, EXP, JEF, or other machine stitch file is included.**

## Artwork choices

- **Wordmark:** SmartTec without the small “by Z1Power” endorsement, for better readability at garment size.
- **Symbol:** The standalone architectural S, for compact placements.
- **2color-dark-fabric:** off-white body and signal-green core.
- **2color-light-fabric:** forest-green body and signal-green core.
- **1color:** one thread color; black artwork is a shape reference, not a requirement to use black thread.

Each choice is supplied as an EPS, an SVG, and a transparent PNG preview. Use the vector file for digitizing. Colors are separated into two filled paths; there are no gradients, shadows, particles, or live fonts. EPS artboard dimensions are scalable artwork dimensions, not an approved embroidery size.

## Instructions for the digitizer

Preserve the S silhouette, its open gaps, and the green connecting core. Keep the logo proportions locked. Confirm that letter counters and narrow gaps remain open at the final sew size. Determine stitch types, underlay, density, pull compensation, sequence, trims, and tie-ins for the chosen material and machine. Produce a sew-out on the intended or equivalent fabric and review it before production.

If the full name is too small for the placement, use the symbol rather than compressing the wordmark or closing its gaps. The full endorsed lockup is available in `../logos/eps/` if a large placement can support it.

## Color targets

- Forest green: **#1C4839**.
- Signal green: **#7BE88A**.
- Off-white: **#EEF1EF**.

Hex values describe the visual targets. They are not thread color codes; choose the nearest approved physical thread swatches.
